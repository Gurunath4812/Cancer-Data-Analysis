# Cancer-Data-Analysis
"Predictive statistical framework using PCA and Logistic Regression to analyze 1,000 patient records and identify gender-based diagnostic trends."

Cancer Diagnostic Statistical Framework 
Project Overview Developed a predictive framework to analyze 1,000 patient records, identifying critical diagnostic trends for gender-based preventive healthcare strategies. This project leverages advanced statistical methodologies to provide quantified medical insights and improve diagnostic accuracy.

Statistical Methodology
Principal Component Analysis (PCA): Integrated PCA to handle high-dimensional medical data, resulting in an 85% variance explanation. This reduced noise while preserving critical diagnostic features.
Hypothesis Testing: Conducted Chi-Square testing ($p < 0.05$) to identify statistically significant correlations between gender, age groups, and diagnostic severity.
Modeling: Utilized Logistic Regression and Decision Trees to build the diagnostic framework, focusing on the probability of stage transitions.
Probability Theory: Applied Poisson Process modeling to estimate mutation rates (e.g., APC gene mutations) over time.

Key Results
Quantified Risk: Determined through Odds Ratio analysis that males are 3.1x more likely to experience high-risk factors compared to other demographics in the study.
Model Accuracy: Achieved a significant increase in prediction accuracy for cancer severity through rigorous feature selection and dimensionality reduction.
Data Storytelling: Presented findings via interactive heatmaps and Machine Learning classifiers to communicate risks to healthcare stakeholders.
